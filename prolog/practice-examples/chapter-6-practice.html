Q1: f(X,Y) With 3 Rules + Query

  • لو عندنا الـ Rules دي:
f(X, 0) :- X < 3.            % Rule 1
f(X, 2) :- 3 =< X, X < 6.    % Rule 2
f(X, 4) :- 6 =< X.           % Rule 3
  1. اكتب الـ Program تاني باستخدام Green Cut.
  2. اكتب الـ Program تالت باستخدام Red Cut.
Solution (f(X,Y) with 3 Rules)

أ) Green Cut:

f(X, 0) :- X < 3, !.
f(X, 2) :- 3 =< X, X < 6, !.
f(X, 4) :- 6 =< X.

ب) Red Cut:

f(X, 0) :- X < 3, !.
f(X, 2) :- X < 6, !.
f(X, 4).

Q2: max(X, Y, Max) with and without Cut

  1. اكتب دالة max من غير Cut.
  2. اكتب دالة max باستخدام Red Cut.
Solution (max with and without Cut)

أ) من غير Cut:

max(X, Y, Max) :- X >= Y, Max = X.
max(X, Y, Max) :- X < Y, Max = Y.

ب) بـ Red Cut:

max(X, Y, Max) :- X >= Y, !, Max = X.
max(X, Y, Max) :- Max = Y.

Q3: Conditional Function (X ≤ 5, X > 5)

  • اكتب دالة f(X, Y) تحقق العلاقة دي باستخدام Cut:
    1. ا Rule 1: لو X =< 5 يبقى Y = 3X
    2. ا Rule 2: لو X > 5 يبقى Y = X² + 5
Solution (Conditional Function)

بدون Cut:

f(X, Y) :- X =< 5, Y is 3 * X.
f(X, Y) :- X > 5, Y is X ** 2 + 5.

باستخدام Cut:

f(X, Y) :- X =< 5, !, Y is 3 * X.
f(X, Y) :- Y is X ** 2 + 5.

Q4: Classify Number (Positive / Zero / Negative)

  • اكتب دالة class(Number, Category) تصنف الأعداد لـ positive, zero, أو negative باستخدام Cut.
Solution (Classify Number)
class(Number, positive) :- Number > 0, !.
class(0, zero) :- !.
class(Number, negative).

Q5: Simple Functions

  1. اكتب دالة function(X, Y) تشوف: y = 3x + 2
  2. اكتب دالة fun(X, Y) تشوف: لو X ≤ 3 يبقى Y = 2X، ولو X > 3 يبقى Y = 4X + 5
Solution (Simple Functions)

أ) y = 3x + 2:

function(X, Y) :- Y is 3 * X + 2.

?- function(2, Y).
Y = 8.

ب) Two-rule function:

fun(X, Y) :- X =< 3, Y is 2 * X.
fun(X, Y) :- X > 3, Y is 4 * X + 5.

?- fun(2, Y).
Y = 4.

?- fun(5, Y).
Y = 25.

Q6: split (Positives and Negatives)

  • اكتب دالة split(Numbers, Positives, Negatives) اللي بتقسم List الأرقام لـ List فيها الأرقام الموجبة (ومعاها الصفر) و List فيها الأرقام السالبة.

  • وجربها على: ?- split([3, -1, 0, 5, -2], P, N).

Solution (split/3)
split([], [], []).
split([X|L], [X|L1], L2) :- X >= 0, !, split(L, L1, L2).
split([X|L], L1, [X|L2]) :- split(L, L1, L2).

تجربة:

?- split([3, -1, 0, 5, -2], Pos, Neg).
Pos = [3, 0, 5],
Neg = [-1, -2].

Q7: Tennis Player Classification

  • لو عندنا Database:
beat(tom, jim).
beat(ann, tom).
beat(pat, jim).

  • وصنفنا اللاعيبة لـ:

  • Winner: كسب كل الماتشات

  • Fighter: كسب وخسر ماتشات

  • Sportsman: خسر كل الماتشات

  • اكتب دالة class(Player, Category) باستخدام Cut.

  • طلع ناتج الاستعلامات دي:

    1. ?- class(tom, C).
    2. ?- class(ann, C).
    3. ?- class(jim, C).
Solution (Tennis Classification)

أ) الـ Rules:

class(X, fighter) :- beat(X, _), beat(_, X), !.
class(X, winner) :- beat(X, _), !.
class(X, sportsman) :- beat(_, X).

ب) النواتج:

1) ?- class(tom, C).
   C = fighter.   % Tom beat(jim) و beat(ann,tom)

2) ?- class(ann, C).
   C = winner.    % Ann beat(tom) ومحدش beat(ann)

3) ?- class(jim, C).
   C = sportsman. % محدش beat(jim) و beat(tom,jim) و beat(pat,jim)

Q8: member vs member1

  • اكتب ناتج الاستعلام ده باستخدام member:
?- member(X, [a, b, c]).
  • اكتب ناتج الاستعلام ده باستخدام member1 (اللي فيها Cut):
?- member1(X, [a, b, c]).
  • اشرح ليه النتائج مختلفة.
Solution (member vs member1)

أ) member (من غير Cut - بتطلع كل الحلول):

X = a ;
X = b ;
X = c.

ب) member1 (بـ Cut - بتطلع أول حل بس):

X = a ;
no

جـ) الفرق:
ا member1 فيها ! بعد أول Base Case، فلما أول حل ينجح (X = a)، الـ Cut بيمنع أي محاولة Backtracking للقاعدة التانية وخلاص.

Q9: add with Cut (No Duplicates)

  • لو عندنا الدالة:
add(X, L, L) :- member(X, L), !.
add(X, L, [X|L]).

  • طلع ناتج الاستعلامات دي:

    1. ?- add(a, [b, c], L).
    2. ?- add(X, [b, c], L).
    3. ?- add(a, [b, c, X], L).
    4. ?- add(a, [a, b, c], L).

  • ايه اللي هيحصل لو شيلنا الـ Cut من الدالة فوق، وجربنا الاستعلام الرابع تاني؟

Solution (add with Cut)

أ) النواتج:

1) ?- add(a, [b, c], L).
   L = [a, b, c].     % a مش موجود، فاتضاف

2) ?- add(X, [b, c], L).
   L = [b, c],
   X = b.             % X اتحطت مع member

3) ?- add(a, [b, c, X], L).
   L = [b, c, a],
   X = a.             % member نجح مع X = a

4) ?- add(a, [a, b, c], L).
   L = [a, b, c].     % a موجود فعلاً، مترجعش نفسها من غير إضافة

ب) من غير Cut:

?- add(a, [a, b, c], L).
L = [a, b, c] ;     % member نجح
L = [a, a, b, c].   % Backtracking شغل القاعدة التانية وضافت duplicate
